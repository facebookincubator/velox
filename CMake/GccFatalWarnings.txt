# GCC warnings that fail the build when TREAT_WARNINGS_AS_ERRORS is on. GCC
# reports every other enabled warning without failing.
#
# Internal Velox builds only with Clang, so a GCC warning reaches GitHub
# unchecked and can break the OSS build. Each warning here has a Clang warning
# of the same name that internal Velox's Clang build treats as an error.
#
# nonnull and tautological-compare are left out: GCC reports them on code that
# Clang accepts (nonnull after inlining, for example), so internal Velox cannot
# catch them.
#

# not know are skipped.
