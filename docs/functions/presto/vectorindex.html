Vector Index Functions¶

A VECTOR_INDEX is a local vector index: a FAISS index over embeddings, with each embedding’s id, serialized as faiss::write_index writes it and stored as VARBINARY. vector_index_build(), vector_index_pack() and vector_index_train() return it, and vector_count() counts the embeddings of many.

This function is available when Velox is built with FAISS (VELOX_ENABLE_FAISS).

cardinality(index) → bigint

Returns the number of embeddings in the vector index index.
